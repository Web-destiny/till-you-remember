# Графика расширения RPG

Все изображения созданы встроенным `image_gen.imagegen`, без CLI/API и без внешних зависимостей. Финальные файлы скопированы из каталога генерации в проект; исходные файлы генератора сохранены. Цветовой тип PNG проверен по заголовку. Альфа-канал прозрачных атласов сохранён без перекодирования. Изображения визуально проверены.

Точные размеры результата могут отличаться от запрошенных в промпте. Для обрезки атласов необходимо брать фактические `image.width` и `image.height`.
