# Публикация на GitHub Pages

Игра — статические HTML, CSS, JavaScript и PNG. Для игроков нет входа в GPT или GitHub. Игровой код не обращается к GPT и не требует сервера Node.js в продакшене. Адрес Pages будет `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`; можно подключить собственный домен.

## Автоматическая публикация

1. Создайте репозиторий GitHub и загрузите в него содержимое архива `till-you-remember-github.zip`. В корне должны оказаться `package.json`, папка `dist/` и `.github/workflows/pages.yml`.
2. На GitHub откройте **Settings → Pages → Source → GitHub Actions**.
3. Пуш в `main` или `master` запустит проверку синтаксиса и публикацию. Также можно запустить **Actions → Publish game to GitHub Pages → Run workflow**.
4. Откройте адрес, указанный успешным шагом deployment. Публикуется только `dist/`.

Сборка и установка npm-зависимостей не требуются. В workflow используются официальные `actions/checkout`, `actions/configure-pages`, `actions/upload-pages-artifact`, `actions/deploy-pages`.

GitHub Pages на GitHub Free поддерживает публичные репозитории. Возможности закрытых репозиториев зависят от тарифа. Подробности: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

## Публикация без Actions

Распакуйте `till-you-remember-static.zip` и загрузите его содержимое в корень отдельного репозитория. `index.html` должен лежать в корне, папка `assets/` — рядом. В **Settings → Pages** выберите **Deploy from a branch → main → /(root)**. Не загружайте сам zip вместо распакованных файлов.

Этот же архив подходит для любого обычного статического хостинга. `.nojekyll` уже включён. Все пути к модулям, стилям и изображениям относительные; работа из подпапки проверена браузерным тестом.

## Свой домен

Укажите принадлежащий вам домен в **Settings → Pages → Custom domain**, затем настройте DNS по инструкции GitHub: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/about-custom-domains-and-github-pages

## Перенос прогресса

Хранилище браузера привязано к адресу сайта. До перехода на новый адрес откройте старую игру → **Пауза → Скачать сохранение в файл**. На новом сайте откройте паузу или справку на титульном экране → **Загрузить сохранение из файла**. Поддерживаются сохранения первой и второй версий. Экспорт включает инвентарь, экипировку, дом, профессии и отношения с Амо.

## Что подготовлено локально

Архивы содержат только файлы игры и необходимые материалы для запуска. В готовый репозиторий не входят `.git`, служебная конфигурация исходного хостинга `.openai`, ключи, сохранения игрока или результаты локальных тестов.
