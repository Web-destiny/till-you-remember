# Пока ты помнишь / Till You Remember

Законченная небольшая первая глава одиночной браузерной action RPG. Основной формат — вертикальный экран телефона, без установки и поворота экрана. Три класса, бой в реальном времени, сюжет о похищенной Амо, диалоги, три воспоминания, побочный квест, торговля зельями, уровни и босс. После завершения можно остаться в мире; Амо следует за героем.

## Запуск

Требуется Node.js 18 или новее; зависимости для самой игры не нужны.

```sh
node server.mjs
```

Откройте http://127.0.0.1:4173. Для статического хостинга достаточно содержимого `dist/`. Запуск через HTTP обязателен: приложение использует модули JavaScript.

## Управление

На телефоне: джойстик слева, удержание большой кнопки справа для атаки, маленькая кнопка справа для рывка, три квадратные кнопки для умений и сердце для зелья. Вблизи персонажа или воспоминания появляется кнопка взаимодействия. Цель отмечена символом ◇. Игра выбирает ближайшую цель для удара.

На компьютере: WASD или стрелки — движение; клик или K — атака; 1/2/3 — умения; пробел — рывок; F — взаимодействие; Q — зелье; J — журнал; M — карта; Esc — пауза. Звук включается отдельно в верхнем правом углу.

Прогресс сохраняется автоматически в localStorage браузера каждые восемь секунд, при важных событиях и уходе со страницы. Есть ручное сохранение в меню паузы. Сохранение привязано к браузеру, устройству и адресу сайта; серверной синхронизации нет. При потере фокуса игра ставится на паузу.

## Файлы

- `dist/game.js` — игровой цикл, управление, столкновения, классы, бой, квесты, диалоги, сохранения и звук Web Audio.
- `dist/art.js` — камера, анимация, спрайты, освещение и эффекты Canvas 2D.
- `dist/assets/` — оригинальная карта и прозрачные спрайты, созданные встроенным Imagegen. Подробные промпты: `ASSETS.md`.
- `dist/style.css` — вертикальный интерфейс телефона и адаптация для компьютера.

Это играбельная первая глава, а не большая законченная RPG. Карта нарисована единым изображением с согласованными зонами столкновения; перемещение, противники, снаряды, эффекты и взаимодействия рассчитываются в реальном времени. Дома декоративные. Классы используют общий анимированный спрайт с разными цветами плаща и разными характеристиками и умениями. Стиль ориентирован на второй пользовательский референс; изображение не является его точной копией.

## Проверка

`npm run check` проверяет синтаксис модулей.

`qa-smoke.mjs` — браузерная проверка с Playwright. Она проверяет вертикальные экраны 390×844 и 375×667, рабочий стол 1440×900, выбор класса, вступление, сенсорный джойстик, движение, сохранение и восстановление, диалог, урон и перезарядку умений, сбор всех воспоминаний, переход после смерти босса и концовку. Для перехода между этапами используются подготовленные сохранения; здоровье босса в проверке финального перехода снижено. Полный баланс долгого боя тестом не оценивается. Ошибки JavaScript также проверяются. Скриншоты сохраняются в `qa-output/`.

Для запуска установите Playwright в окружение разработки и его Chromium, запустите сервер, затем `node qa-smoke.mjs`. Для уже установленного Playwright можно задать `PLAYWRIGHT_MODULE` (URL модуля) и `PLAYWRIGHT_CHROMIUM` (путь к браузеру).
